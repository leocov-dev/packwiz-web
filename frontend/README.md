# packwiz-web Frontend

## Dependencies

- Node as specified in [package.json](package.json) (`engines.node`)
- npm


## Local

```
# install dependencies
npm install

# run dev server locally
npm run dev

# build
npm run build

# lint
npm run lint

# type-check
npm run type-check

# run unit tests
npm run test
```
